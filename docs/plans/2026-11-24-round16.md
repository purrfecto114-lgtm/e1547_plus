### Task 1: 修复 server.dart 运算符优先级 bug（#4 排序失效）

**Files:**
- Modify: `lib/follow/data/server.dart` (line 89)
- Test: `test/follow/data/server_test.dart`

**Step 1: Write the failing test**
在 `FollowServer.syncWith` group 追加：
```dart
test('marks the follow seen by default and keeps unseen when seen=false', () async {
  final follow = await seedFollow();
  await repository.replace(follow.copyWith(unseen: 7, latest: 2, thumbnail: '/p/2'));

  await server.syncWith(id: follow.id, posts: [samplePost(id: 2, preview: '/p/2')]);

  final updated = await repository.get(follow.id);
  expect(updated.unseen, 0); // 默认浏览即已读

  await repository.replace(updated.copyWith(unseen: 7));
  await server.syncWith(id: follow.id, posts: [samplePost(id: 2, preview: '/p/2')], seen: false);
  expect((await repository.get(follow.id)).unseen, 7); // seen=false 保留未读
});
```

**Step 2: Run test — confirm it fails**
`flutter test test/follow/data/server_test.dart`
Expected: FAIL — 当前 `seen ?? true ? Value(0) : Value.absent()` 在 seen=false 时也写 0（`seen ?? (...)` 对非 null seen 直接取 seen=false… 实际 false 时走 `??` 右侧？不：seen=false 非 null，表达式= false → 应走 absent。需先跑测试观察实际行为再断言真实缺陷方向）。

**Step 3: Write minimal implementation**
```dart
unseen: (seen ?? true) ? const Value(0) : const Value.absent(),
```

**Step 4: Run test — confirm it passes**

**Step 5: Commit** `fix: parse the seen fallback with explicit parentheses in syncWith`
