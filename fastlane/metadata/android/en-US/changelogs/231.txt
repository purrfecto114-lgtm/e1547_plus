The lock's pin hash is five times harder to brute force offline: the key derivation now runs the same 150000 rounds as the database export, existing installs upgrade themselves the next time the pin verifies, and the notes no longer claim a four digit space is expensive to sweep. Password-protected exports no longer freeze the screen: the cipher runs on the platform's native aes on android, ios and macos, and on a background thread everywhere else.
Only web links leave the app: markup links and post sources carrying other schemes (market:, mailto:, …) are refused with a notice instead of being handed to the system. Downloads stop at two gigabytes, so a hostile upload cannot park an arbitrarily large file on the device.
A post whose original file the server dropped no longer takes the whole page down with it; its dimensions fall back to the tiers that survive. The pin backoff cannot be talked into waiting less by pushing the clock forward, and a stamp written under a fake clock never locks the rightful owner out for longer than one maximum wait. Redacting long urls out of the logs no longer stalls the ui thread, the history and follow lists filter by account through their index again instead of scanning the whole table, the donors page avatars go through the app's image cache like every other image, and ios backups skip the preferences file that holds the pin hash, the same way android's cloud backup already does.
